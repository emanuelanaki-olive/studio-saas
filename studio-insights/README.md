# Studio Insights

מערכת ניתוח, התראות ודוחות לסטודיו שעובד עם Arbox. היא נפרדת ממערכת הניהול ורק קוראת ממנה נתונים.

- **דשבורד** (Streamlit): תפוסה לפי יום ושעה, רווח לפי מתחם, מתאמנות בסיכון נטישה, דפוסי הגעה, ניצול מנויים והקפאות.
- **דוח יומי מקוצר** בוואטסאפ בסוף כל יום.
- **דוח שבועי מלא** בוואטסאפ בכל יום ראשון בבוקר, כולל המלצות ולוח שנה של חגים.

## מקור הנתונים

| שלב | מקור | סטטוס |
|---|---|---|
| עכשיו | דוחות Excel מ-Arbox: `shift-summary-report` (הרשמות) ו-`members-on-hold-report` (הקפאות), שמים אותם בתיקייה `data/` | ✅ עובד |
| בהמשך | Arbox API, לפי `insights/ingest/arbox_api.py` | ⏳ מחכה למפתח API מ-Arbox |

כל שאר המערכת (חישובים, דוחות, דשבורד ווואטסאפ) עובדת על אותו מודל נתונים (`insights/data.py`). לכן המעבר ל-API ידרוש לשנות רק את קוד טעינת הנתונים.

## התקנה

```bash
cd studio-insights
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp config.example.yaml config.yaml   # מחירים, קיבולת, שכר, הוצאות, ספי התראות
cp .env.example .env                 # מפתחות WhatsApp (ו-Arbox בהמשך)
```

מעתיקים את דוחות ה-Excel מ-Arbox לתיקייה `data/`. קובצי `data/`, `config.yaml` ו-`.env` לא נשמרים ב-git, כי יש בהם שמות מתאמנות וסודות.

## הרצה

```bash
python -m insights daily              # דוח יומי (מודפס + נשמר ב-reports/)
python -m insights weekly             # דוח שבועי
python -m insights weekly --dry-run   # מציג את הודעות הוואטסאפ בלי לשלוח
python -m insights daily --send       # שולח לוואטסאפ
streamlit run dashboard/app.py        # דשבורד
pytest                                # בדיקות
```

## WhatsApp

השליחה עוברת דרך WhatsApp Cloud API של Meta. כדי שזה יעבוד צריך:

1. חשבון Meta Business ומספר טלפון ייעודי ל-WhatsApp Business. מקבלים `WHATSAPP_TOKEN` ו-`WHATSAPP_PHONE_NUMBER_ID`.
2. **תבנית הודעה מאושרת**: Meta מאפשרת לשלוח טקסט חופשי רק אם הנמען כתב למספר העסקי ב-24 השעות האחרונות. לדוחות קבועים צריך ליצור תבנית עם משתנה אחד, למשל `{{1}}`, ולהגדיר `whatsapp.mode: template` ב-`config.yaml`.
3. להגדיר בשדה `whatsapp.recipients` מספרים בפורמט בינלאומי, בלי `+`.

## הנחות חישוב

- **הכנסה:** כל מנויה שהתאמנה בחודש נספרת כמי ששילמה את מחיר המנוי שלה. ההכנסה מחולקת בין המתחמים לפי מספר האימונים שלה בכל אחד. המחירים כוללים מע"מ, והרווח מחושב בלי מע"מ.
- **שכר מאמנות:** משולם רק על שיעור עם 2 מתאמנות ומעלה. שיעור עם מתאמנת אחת בין שני שיעורים של אותה מאמנת = 80 ₪.
- **הוצאות קבועות:** מחולקות בין המתחמים לפי החלק של כל מתחם במספר האימונים.
- **ניצול מנוי:** אימונים בפועל מול הכניסות במנוי, אחרי שמורידים את ימי ההקפאה.
- **בסיכון נטישה:** לא הגיעה 14 יום ומעלה, לא בהקפאה ואין לה הרשמה עתידית. **עזבה:** 30 יום ומעלה.
- **חגים:** מחושבים אוטומטית לפי הלוח העברי (`pyluach`).
